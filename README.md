# Mini CRM (HTML, CSS, JS)

Aplicación CRM básica construida con tecnologías web simples.

## Funciones incluidas

- Alta y listado de clientes.
- Alta y listado de oportunidades comerciales.
- Alta y listado de tareas.
- Eliminación de clientes/oportunidades/tareas.
- Dashboard con KPIs (clientes, oportunidades, pipeline, oportunidades en cierre y tareas vencidas).
- Persistencia local con `localStorage`.

## Cómo usar

1. Abre `index.html` en tu navegador.
2. Crea clientes.
3. Registra oportunidades asociadas a clientes.
4. Añade tareas de seguimiento.

## Nota

Esta versión está pensada como MVP y no requiere backend.
